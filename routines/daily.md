# Couch Kick-Off daily update (instructions for the 09:39 routine)

You are updating Gareth's public website **Couch Kick-Off** (https://couchkickoff.co.uk), a guide to men's football on UK TV. Do not use em dashes in anything you write. Check the current UK date and time first (Europe/London).

## Where the site lives

- This repository (ki55tbh/couch-kick-off) is the only master copy. The whole site is `index.html` on branch `main`. GitHub Pages republishes the site about a minute after every push to `main`.
- The older claude.ai artifact pages are retired: do not read or edit them.
- Only edit the data parts of `index.html` listed below. Never change the layout, styles, scripts, the About section, the Report links, the team page links between the TEAMPAGES markers, or the Cloudflare Web Analytics snippet just before `</body>` (it counts visits; `tools/validate.py` fails if it is missing).

## Data format

Inside the page script, these are the data parts you maintain:

1. `const UPDATED = {last_ok:'YYYY-MM-DDTHH:MM', last_attempt:'YYYY-MM-DDTHH:MM', status:'ok', summary:'...'};` (UK local time, 24h). The page shows "TV picks updated: <last_ok>", or a warning if status is 'failed'.
2. The template string `const RAW = \`...\``. Each line is one game: `YYYY-MM-DD HH:MM|Home|Away|COMP|CHANNELS|optional note`
3. The `const KIT={...};` club colour map, and the footer list under `<h4>Confirmed TV picks so far</h4>`. Whenever you add a line with a team that is not yet in KIT, add that team to KIT in the same run, as `"Team":["#main","#second"]` using its main home kit colours (spelling exactly as in RAW). Skip placeholder names such as "X or Y" or round labels.
4. The `const VENUES = {...};` map of match venues, keyed `"YYYY-MM-DD|Home|Away"` with exactly the date and team spellings of the RAW line, value `"Stadium, City"` (add the country in brackets if the city isn't in the home nation, e.g. a neutral venue). Each card shows its venue under the competition. This covers international matches (senior and U21 internationals: Nations League, qualifiers, friendlies) and any club match away from its usual ground. For every international in the next 10 days with no venue, add one when the home federation, UEFA, the stadium or another reliable source names it; never guess. If a match moves venue or date, update or re-key its entry.
   Club matches get their venue automatically from `const GROUNDS={...};` (home team → "Stadium, City"). Only add a VENUES entry for a club match when it is NOT at the home team's usual ground: a neutral venue (cup semi-final or final, e.g. Wembley or Hampden), a temporary or moved ground, or a European "home" game played elsewhere. If a club appears as a home team with no GROUNDS entry, add one only when you are sure of the ground (club website or league site); otherwise leave it blank. Never guess.
4. `const AUDITS = [...]` belongs to the Monday audit. Leave it alone.

- Times are UK local time. Time can be TBC. COMP uses codes (PL, CH, L1, L2, UCL, UEL, UECL, SPL, CC, NL, EQ = Euro 2028 Qualifiers, LL = LaLiga, SA = Serie A, BL = Bundesliga, FA Cup etc) or a literal name such as "International Friendly".
- CHANNELS is comma-separated. Short tokens expand via the CH map: S = "Sky Sports|NOW", SF = Sky Sports Football, SP = Sky Sports+, SME = Sky Sports Main Event + Sky Sports Football, T = "TNT Sports|HBO Max", PS = Premier Sports, DIS = Disney+, DZ = DAZN, PPV = Prime Video PPV, TBC = "TV pick TBC", NOTV = "Not on UK TV". Any other text is shown literally, e.g. "Sky Sports Main Event,Sky Sports Premier League,Sky Sports UHD 1,NOW" or "ITV1,ITVX" or "BBC One,BBC iPlayer" or "BBC ALBA,BBC iPlayer" or "S4C" or "YouTube (That's Football)". Any channel containing "YouTube" gets the red YouTube badge and appears under the YouTube and Free to watch filters.
- EXPECTED vs CONFIRMED: a channel token ending in "?" (e.g. "PS?", "DZ?", "DIS?") means EXPECTED: the broadcaster holds the competition's UK rights (or that slot) but has not confirmed that individual match. The page shows an outlined badge with an "Expected" label. A token without "?" means the broadcaster has confirmed that specific match. Never mark a game confirmed just because the broadcaster owns the rights. Remove the "?" only when the broadcaster's own schedule, or a reliable UK TV listing such as FotMob's UK TV guide, names that specific match on that channel, and use the exact channel if listed (e.g. "Premier Sports 1"). Never list two broadcasters on one game unless a listing shows that match on both. Currently "?" is used on LaLiga (PS?, DIS?) and Serie A (DZ?).
- Lines with an empty Away field are placeholder events (e.g. "FA Cup third round||FA Cup|...").
- Men's football only. Team names must match existing spellings in RAW (e.g. "Manchester United", "Tottenham Hotspur", "Bournemouth", "Brighton", "West Bromwich Albion", "AC Milan", "Inter", "Bayern Munich", "Stuttgart", "Cologne", "Borussia Mönchengladbach", "Atlético Madrid", "Athletic Club", "Celta Vigo", "Deportivo La Coruña"). For national teams use "England", "Scotland", "Wales", "Northern Ireland", "Republic of Ireland" and the opponent's English country name. If you add a club or country not yet in KIT, add it there with its primary and secondary colour.

Before editing, save a copy of the current RAW block so you can compare afterwards. Make edits with a short Python script or careful text replacement on `index.html`.

## Priority every day

Today and the next 2 days must be right. Check them against a live UK listing (FotMob UK TV guide first) for late channel changes, moved kick-offs and postponements, and fix them. On days with little time, do this and the stamp, and leave the longer-range tasks for the next run.

## Work out what changed

Compare old RAW with new RAW and count: new televised fixtures confirmed; expected broadcasts confirmed ("?" removed); channel changes; time/date changes; games moved to "Not on UK TV". Put a one-line version in UPDATED.summary.

## Stamp, check and publish

- Success: set UPDATED.last_ok and UPDATED.last_attempt to the current UK date/time, taken from `TZ=Europe/London date +%Y-%m-%dT%H:%M` run just before you write it (never estimate it), status 'ok', summary as above (publish even with no fixture changes, so the "last checked" date is current).
- Failure (could not reach enough sources): do NOT change RAW. Set only UPDATED.last_attempt to now (from `TZ=Europe/London date +%Y-%m-%dT%H:%M`) and status 'failed', leaving last_ok as it was.
- Rebuild the team pages: `node tools/build_pages.mjs`. It regenerates the team folders (e.g. `liverpool/index.html`), the competition and weekend folders (e.g. `premier-league-on-tv/index.html`, `football-on-tv-this-weekend/index.html`), `sitemap.xml`, the team links between the TEAMPAGES markers and the "On UK TV today" summary between the TODAYTV markers in `index.html` from RAW, plus the `ck-build` fingerprint meta tag in the head. Never edit those by hand.
- Run `python3 tools/validate.py`. It checks index.html AND that every team page and the sitemap exactly match RAW. If it fails, fix the problem, then run `node tools/build_pages.mjs` and `python3 tools/validate.py` once more (one retry only). If it still fails, publish NOTHING: run `git checkout . && git clean -fd` so the last fully validated website stays live, and report the failure clearly with the validator's error. Never publish index.html without matching team pages.
- Confirm `git diff --stat` and `git status --short` only touch index.html, sitemap.xml and the team, competition and weekend page folders.
- Commit and push: `git add -A && git -c user.name="Claude" -c user.email="noreply@anthropic.com" commit -m "Daily update YYYY-MM-DD: <summary>"` then `git push origin HEAD:main`. If rejected because main moved, `git pull --rebase origin main` once and push again.
- If the push to main is refused for permissions (e.g. 403), do not retry it. Instead push the same commit once to the fallback branch: `git push --force origin HEAD:claude/live`, and report that main was refused and which branch received the update. Do not try any other way in.
- Confirm with `git ls-remote origin main claude/live` which branch has your commit.

## Finish

End with a short summary (include the "Team pages OK: N team pages" line from validate.py, or if nothing was published, say so and why) as your final message: "Couch Kick-Off updated: 4 new televised fixtures confirmed, 2 channel changes, 1 kick-off time moved." plus one line naming anything notable, the commit hash, and the link https://couchkickoff.co.uk. If anything failed, say so plainly first, including whether the website was updated.
